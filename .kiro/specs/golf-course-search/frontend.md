# フロントエンド設計書
## 入力欄
| ラベル名 | 楽天GORAの入力パラメータ名 | 入力形式 | 必須 | 備考 |
| ---- | ---- | ---- | ---- | ---- |
| エリア | areaCode | プルダウン | 必須 | 北海道～沖縄の47都道府県が選択可能<br>都道府県とパラメータに渡す値の組み合わせは別途記載 |
| プレー日 | playDate | カレンダー入力 | 必須 | YYYY-MM-DD形式でAPIに送る |
| 最小価格 | minPrice | 入力フォーム | 任意 | intのみ入力許可 |
| 最大価格 | minPrice | 入力フォーム | 任意 | intのみ入力許可 |
| スタート時間 | startTimeZone | チェックボックス | 任意 | 複数選択した場合は「&startTimeZone=5,7,9」のように入力パラメータへ<br>時間帯とパラメータに渡す値の組み合わせは別途記載 |
| 出発地住所 | なし<br>（GoogleMapAPIに渡すので後ほど確認します） | 入力フォーム | 任意（GoogleMapAPIから値取得する処理を実装後は必須にします） |  |
| 移動時間 | なし | int | 任意<br>（GoogleMapAPIから値取得する処理を実装後は必須にします） |  |

## ボタン
* 検索：押下後、バックエンドに値が送信される
* クリア:押下後「値をクリアしてよろしいですか？」というconfirmが表示される。「OK」押下後入力値をすべてクリア
